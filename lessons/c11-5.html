Objectives

Teaching

You already designed HTTP APIs. Now you see HTTP as bytes on a TCP connection: start line, headers, , body with a length or a chunking scheme. Connection reuse is a performance fact. A reverse proxy, 502, is a hop that speaks HTTP to you and something else upstream.

This module makes C6 and C-syslit sit on C11.1 to 4. If you cannot read the bytes, you cannot debug a bad Content-Length.
