Objectives

  • Run BFS and DFS on a graph given as adjacency lists.
  • State what each is for: shortest unweighted path vs explore, finish times, components.
  • Mark visited so you do not loop forever.
  • Narrate a 6-node graph live.

Teaching

A graph is nodes and edges. C2-remainder will make you implement the ADT. Today I give you adjacency lists and you traverse. BFS uses a queue and gives unweighted shortest path. DFS uses a stack, or the call stack, and is the skeleton of many later algorithms. C5-remainder, C11-ish mental models. Visited is not optional on a cycle. BFS is unweighted shortest path. DFS is explore.

Visited is not optional on a cyclic graph. Forgetting it is the infinite loop of this module. Directed vs undirected changes what neighbor means. I will say which. Forgetting visited is the infinite loop of this module.

Grid problems, islands, are graphs in costume. Same algorithm. Say I will treat cells as nodes out loud so the interviewer knows you know. A grid is a graph in costume. Say that out loud.

BFS shortest path, DFS components, one grid. Narrate. Closed-resource. Draw the graph first. No AI. No MST. No Dijkstra yet. That is remainder.
