C as a language

C9 Computer Systems (C)

Locked. Until Gate A. Systems depth and remaining CS wait until you can apply. You may read so the catalog is a real map. Do not start the exercises or the assigned reading until this lesson is current. Ratings do not move from a URL.

Objectives

  • Write small C programs: compile, run, read a compiler error.
  • Explain why C is in the program, machine model, and why we will not ship product features in it.
  • Use types, int, char, pointers preview, without assuming Python semantics.
  • Keep undefined behavior as a named cliff. C9.9.

Teaching

C is the language of the machine model in this program. You will not build P1 features in C. You will learn how memory looks, because Python and Postgres and the kernel are C-shaped under the floor.

Compile with a compiler I specify gcc or clang, with warnings on -Wall. A warning is a homework fail until you understand it. No IDE magic that hides the compiler invocation. C0 skills apply.

C has no exceptions, no lists, no hash maps in the language. Arrays are contiguous storage. Strings are bytes plus a convention, a trailing NUL byte. You will feel poor. That poverty is the lesson.

CSAPP chapters 1 to 6 selected, plus CS107-style assignments I adapt. We will not do a semester of HDL.

Warnings on. A warning you do not understand is a homework fail. No lists, no exceptions, strings as bytes plus a terminator. Poverty is the lesson. Compile with a command you can repeat. Assistant-written C you cannot read is a fail. Product features stay in Python.

C is in the program for the machine model, not for product work you will ship. Python hid this. That was on purpose. Now you pay the bill so a crash report is not mysticism. You will be slower than in Python. That is the point. Draw before you type. Read the compiler.

Treat a sanitizer hit as a gift. Undefined behavior is not a crash you can shrug at. The hundred-line task is ordinary C, not a trick. If a loop in hiring pokes C, we schedule this course. We do not lower Gate A.
