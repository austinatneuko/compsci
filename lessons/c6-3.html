Relational model

Objectives

  • Draw a relational model: tables, keys, foreign keys, a constraint.
  • Explain a row as a tuple of a relation, not as a JSON object in a spreadsheet.
  • Normalize far enough that one fact does not live in three places.
  • Know when a repeated column is a smell.

Teaching

A relational database stores facts in tables with named columns and a type per column. A primary key names a row. A foreign key says this value must exist as a key over there. Constraints, NOT NULL, UNIQUE, CHECK, are the database refusing to store a lie. If you skip them because the app will check, you will store a lie the first week the app has a bug.

A row is a fact with a key. A foreign key is a refusal to store a pointer to nothing. Nullability is a decision, not a default you forgot. If a fact lives in three places, you will update two.

Normalization is not a purity contest. First normal form: no lists-in-cells we will query as lists. Higher forms: do not copy a user's email into every order if the email is a fact about the user. When history matters, the email at purchase time, you store the snapshot on purpose and name it a snapshot.

ORMs wait. You will think in tables first. People who start with an ORM start with objects and then wonder why the join is a mystery. We will draw schemas on paper. If you cannot draw it, you cannot migrate it.

Draw a schema for a prompt I send: people, things, events. Keys and two constraints. I reject until honest. Find the repeated fact in a bad schema I give you. Write the better tables. Closed-resource. No ORM. No AI.

Backend work in this program is HTTP plus a relational database plus a thin framework, in that order. FastAPI is not the syllabus. If you cannot read a raw request, predict a join, or justify an index, a green OpenAPI page is decoration. We talk to Postgres with parameters before any ORM. Transactions are how two writes become one fact. Validation dies at the edge with a 4xx that names the field. The service you build here is the skeleton of P1. Dishonest schemas get rejected until they are honest. That loop is the course.
