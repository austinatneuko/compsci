Objectives

  • Run Dijkstra or BFS-as-shortest on a weighted/unweighted graph as assigned.

Teaching

Graphs II is the algorithms C5-lite skipped: weighted shortest paths, MST. Dijkstra is BFS with a heap and a caveat, non-negative weights. MST is a different question, connect cheaply, not path to one node. Mixing them in an interview is a tell.

You will implement at least one. The other may be a written proof/walkthrough I score. Skiena's war stories are recommended for taste, not as a substitute for the implementation.

Weighted shortest path is not MST. Mixing them is a tell. Non-negative weights for Dijkstra. Implement one, write the other. Use the C2-remainder ADT. No copied pseudocode you cannot run.

C5-lite taught you to narrate a medium. This course teaches you to classify a new problem, implement when it is the kind we solve, state complexity, and say whether a polynomial exact algorithm is likely. If it is not, you name an alternative: restrict, approximate, or exponential on small n. That sentence is engineering, not a meme about hardness.

Remainder is also a stop rule. Some problems do not have a clever polynomial exact algorithm you are going to invent on a Tuesday. Implementations still have tests. Proofs still have structure. Conceptual exam on NP catches slogans.
