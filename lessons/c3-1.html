Logic and quantifiers

C3 Discrete Mathematics

Locked. Until Gate A. Systems depth and remaining CS wait until you can apply. You may read so the catalog is a real map. Do not start the exercises or the assigned reading until this lesson is current. Ratings do not move from a URL.

Objectives

  • Translate English claims into propositional and predicate logic.
  • Negate a quantified statement correctly.
  • Use truth tables for small formulas; refuse them as a lifestyle for predicates.
  • Spot an invalid inference.

Teaching

Discrete math in this program is CS 70 style: math you will use on programs and algorithms, not a symbol museum. Logic is the start because every spec, every invariant, and every "for all edges" claim is already logic in English. We make the English honest.

Propositions are true or false. Connectives and, or, not, implies have truth tables you will write once and then use as a language. Implication is the one civilians get wrong: false implies anything is true. That is not a trick. It is why a precondition that is false makes a function "vacuously" right. and why you still should not call it.

Quantifiers: for all, there exists. The negation of "every user has an email" is "there is a user without an email," not "no user has an email." I will drill that until it is boring. Nested quantifiers are where graph claims live, "for every node there exists a neighbor…".

You will not write code this course except as examples. Proofs are the work. If that feels like a different subject, good. it is why we deferred it past the gate.
