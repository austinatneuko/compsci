Teaching

C-syslit is not C9 through C11. It is a seatbelt so a junior loop that wanders into what is a process does not end you. A process is a running program with its own memory the kernel protects. A syscall is how it asks the kernel to do something it cannot do itself: read a file, send a packet, allocate certain resources. read() looks like a function. It is a crossing.

One picture: your Python, the standard library, the kernel, the disk. You will draw it. If a line crosses into the kernel, you will mark it. That is the module. Draw user, library, kernel, device. Mark the crossings.

A file descriptor is a handle in the process, not a path string. Threads share the process memory. Processes usually do not. That sentence is enough for now. Races wait for C10. Ports and sockets wait for the next two modules and C11. We are not giving a twenty-minute OS lecture. We are making a picture you can redraw blank.
