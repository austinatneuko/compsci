Objectives

Teaching

FastAPI is the Python web framework on this path. It is not the syllabus. HTTP, SQL, and your module seams are the syllabus. Handlers should parse the request, call something testable, and return a status and a body. If your handler is 80 lines of SQL and string building, we split it. Handlers parse, call something testable, and return. SQL in the handler is a seam we will split.

I will assign FastAPI docs, not a YouTube weekend. You will learn path params, query params, request bodies, response models. You will not wander into every plugin. Pydantic models show up as validation. C6.9 goes deeper. Assigned FastAPI pages only. Do not wander the plugin list.

Talk to Postgres with parameterized SQL first, not with an ORM. If we add an ORM later, you will already know the SQL it is trying to hide. That is the order in the program.

Run it. uvicorn or the equivalent. Hit it with curl or httpie so you see the HTTP you learned in C6.1. A green OpenAPI page is not proof you understand the request. A pretty docs page is not that client.
