Objectives

  • Say a complexity in a sentence you would use in an interview.
  • Distinguish worst-case from average when it matters, hash, and quicksort if we mention it.
  • Compare two snippets by growth, not by one timing on n=10.
  • Refuse O(n) because there is a for-loop without looking at the body.

Teaching

C5-lite is interview-shaped algorithms, not a second theory course. Asymptotics here are spoken. This is linear in the length of the array. The inner scan makes it quadratic. I can do it in linear time with a hash set at the cost of memory. If you cannot say that out loud, a correct leetcode paste is still a fail in a loop.

A complexity sentence names the input and the growth. Counting loops without reading the body is how people call a binary search linear. We use the C2 cost model. Nested loops are not automatically quadratic. Depends on bounds. A hash lookup is average constant, worst linear. Sorting we treat as n log n unless we wrote a worse sort. Recurrences and Master theorem wait for C5-remainder.

Average versus worst case matters for hashes. The gate exam is spoken. Start speaking now. I will make you narrate while you write. Silence plus a perfect function is not the skill. The gate coding exam is Python under a clock while talking. Start talking now.

NP, MST, heavy DP depth are not here. If a problem smells like all subsets of a large n, we say so and pick another problem, or we do a tiny n and name the explosion. NP is not this module.
