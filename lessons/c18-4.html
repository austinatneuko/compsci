Testing, CI, and deploy

C18 Capstone

Locked. Until Gate A. Systems depth and remaining CS wait until you can apply. You may read so the catalog is a real map. Do not start the exercises or the assigned reading until this lesson is current. Ratings do not move from a URL.

Objectives

  • Testing strategy as a document: what is unit, integration, what is not tested and why.
  • CI/CD green. Cloud deploy. A stranger can run or hit the URL.
  • These are rubric lines.
  • A deploy you cannot roll back is a reliability hole.

Teaching

Testing strategy is an artifact, not 'we have some tests.' CI/CD is how it gets to a cloud you operate. Free tier first if possible. The README is an operator doc preview. I will try to run it. If I cannot, the rubric drops.

The capstone is program-complete work after the gate. Requirements, matching architecture and data and API docs, implementation with review, tests and a pipeline and a URL, operability and security and honest performance notes, then an incident I inject and a rubric. Mean at least 3.5 and no 1s. A 5 is rare. Exit: I would let this into a real codebase with notes, not a rewrite. The calendar ending is not a pass.
