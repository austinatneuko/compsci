Teaching

Most frontend bugs that types can catch are this value is one of a few shapes and you treated it as another. A request state is loading, or err with a message, or ok with data. If you model that as a pile of optional fields, you will render data while loading and call it a React bug. A request state as a pile of optional fields will render data while loading. A union with a kind tag will not, if you narrow.

Narrowing is the compiler following your if. If it cannot follow, your check is not the check you think. We will practice until kind discriminants are boring.

Generics appear as Array of T and Promise of T and a function you write that is honestly generic, not a party trick. If you cannot say what T is, do not write the brackets. Generics are Array and Promise and one function you can explain.

Reading types is C7.7's preview. Today you open a type definition and find the function you are calling. Read a declaration file to find the function you are calling.
