Teaching

You type a URL. The browser asks DNS for an address. Say resolve a name to an IP, not the internet's phonebook as a substitute for thought. It opens a TCP connection to a port, 443 for HTTPS. TLS is the handshake that aims to give you confidentiality and authenticity of the server. Details in C11 and C14. HTTP is the request you already know from C6. The server process accepts, maybe talks to Postgres, responds. The browser parses HTML or JSON.

If you mash TLS and HTTP and DNS into the cloud, you fail the oral. Each hop can be the reason it is slow, C-syslit 3. Each hop can fail in a recognizable way: NXDOMAIN, TCP timeout, cert expired, 502, SQL. Each hop has a job and a failure. If you cannot put one sentence on each acronym, the oral will interrupt you and you will mash.
