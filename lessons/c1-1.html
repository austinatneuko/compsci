Values and names

C1 Programming Fundamentals (Python)

Locked. Because C0 module 3 (editor and terminal workflow) is not mastered yet. C1 can start in parallel only after that. You may read so the catalog is a real map. Do not start the exercises or the assigned reading until this lesson is current. Ratings do not move from a URL.

Objectives

  • Separate a value from the name that currently refers to it.
  • Say what type a value has, and why the type decides which operations are legal.
  • Assign, rebind, and print without thinking the variable “is” the number.
  • Evaluate a small expression by hand, including operator precedence you actually use.
  • Refuse magic: if you cannot say what an object is, you do not use it yet.

Teaching

A program is a sequence of instructions that the machine carries out. Before functions, loops, or files, you need a boring, solid picture of the stuff those instructions move around. Python’s stuff is values. A value is a concrete thing: the integer 3, the float 3.0 (which is not the same thing), the string hello, the boolean False. Values have types. The type is the rulebook for what you may do to that value. You do not add a string to a list and hope. You ask what the objects are.

A name is not a box with a number painted on it, though many intro books draw it that way. A name is a reference. Assignment n = 3 means: the name n now refers to the object 3. Later n = 4 does not change the number three. It rebinds the name. If that sounds picky, wait until two names refer to the same list and you mutate it through one of them. The picture you build today is the one that will save you in C1.4.

You will hear “variable.” Fine. I will still ask “what does this name refer to?” because that question still works when the value is a list, a function, or a file handle. “What is in the variable” starts to lie.

Types you must be fluent with this week: int, float, str, bool, and None. None is the value that means “there is no value here.” It is not the string "None" and it is not zero. Beginners also trip on the fact that 3 / 2 is a float in Python 3, and 3 // 2 is integer division that truncates toward negative infinity. You will check, not assume. type(...) and a mental evaluation are both legal tools. Guessing from vibes is not.

Expressions are trees. 2 + 3 * 4 is not a phrase you scan left to right like English. Multiplication binds tighter, so you compute 3 * 4 first. Parentheses are how you write the tree you meant. I will make you parenthesize until I believe you see the tree. A calculator app is not an explanation.

Input and output at this stage are print and later input. print is for you, the human. It is not “the return value.” Functions in C1.3 will return values that never go to the screen unless you print them. If you confuse those two, every test you write in C1.7 will be theater.

Style starts now, not in C4. Names are lowercase with underscores. They describe the value’s role, not its type (count, not n for everything, and not theInteger). You do not reuse a name for a new unrelated idea three lines later to save keystrokes. You do not call a string list. The interpreter will not stop you. I will.

We write Python 3. You run it from the terminal you earned in C0, in a file, not only in a REPL — though the REPL is a good scratchpad. A file that prints four values and their types is a program. Treat it like one: save, run, read the output, change, commit when the change was on purpose.

Closed-resource this lesson. No model completing your assignments. If VS Code offers a ghost function, ignore it. I want your wrong guesses, because your wrong guesses tell me which picture to fix.

Work

Exercises are listed so you can see the shape of the work. They are not assigned. Do not start them. No solutions on this site.

  1. On paper, without running code: what does each name refer to after a = 2, b = a, a = 5? Then run it and print. If your paper was wrong, write one sentence about which picture failed.
  2. Write a 15-line program that binds at least one int, float, str, bool, and None. Print each value and type. Run it from the terminal, not from a play button you do not understand.
  3. Parenthesize 2 + 3 * 4 ** 2 in two different ways that change the value. Compute both by hand, then confirm.
  4. Find one operation that is legal on ints and illegal on strings (or the reverse). Trigger the error on purpose. Read it. Do not fix it with a guess — explain the type complaint in chat.
  5. Closed-resource. No AI. No copying a tutorial’s “hello variables” file.
