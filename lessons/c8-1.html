Authn vs authz

C8 Auth, Quality, Delivery

Objectives

  • Define authentication, who you are, vs authorization, what you may do.
  • List a default-deny rule: if the check is missing, the answer is no.
  • Place checks on the server. The UI hiding a button is not authz.
  • Write one sentence you could defend in an interview.

Teaching

Authentication is the act of establishing identity: login, session, token. Authorization is the decision about a resource: this user may read this order, may not read that one. Collapsing them into auth is how people ship a product where any logged-in user can GET another user's email.

Default deny. A missing check is not we'll add roles later. It is an open door. Server-side is the law. A React route guard is a courtesy. I will call your API with curl as a user who should be denied. If the JSON comes back, you failed, even if the button is hidden. The UI hiding a button is not authorization. I will curl as the wrong user.

We will write the vocabulary before the mechanisms in C8.2. If you cannot say the words, the JWT blog post you will find will own you. Vocabulary before mechanisms.

For your C6/C7 app, list resources and who may do what. I mark holes. I curl as the wrong user. You fix the server. Closed-resource. No AI policy essay.

Quality and delivery are not a last-week add-on. Authz is on the server. If that sentence makes you want to hide a button and call it security, reread this module.

C8 is how a web app becomes something I would type a password into. Authn is not authz. Sessions or tokens you can defend. Integration tests through HTTP. CI that can go red. Docker enough to run twice. A real URL. Logs with a request id. An OWASP-lite checklist with evidence. I will break the URL on purpose. The exit is not a certificate. It is: I create an account, I use the product, you show me the pipeline, a failing test you wrote, and what you would do if the deploy is bad.

The UI hiding a button is not authorization. I will curl as the wrong user. Default deny. If the check is missing, the answer is no, not we will add roles later. Write the resource list. I mark holes. Vocabulary before mechanisms.
