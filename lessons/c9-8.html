Locked. Until Gate A. Systems depth and remaining CS wait until you can apply. You may read so the catalog is a real map. Do not start the exercises or the assigned reading until this lesson is current. Ratings do not move from a URL.

Objectives

  • State the memory hierarchy: registers, cache, DRAM, disk. as a performance fact.
  • Explain locality, spatial, temporal, with one loop that has it and one that does not.
  • Know that cache lines exist without designing a cache.
  • Connect to "why an array walk beats a pointer chase" sometimes.

Teaching

The machine is not a flat array of bytes at uniform cost. Caches hold recently used lines. A tight array walk is fast because of spatial locality. A linked-list walk can be slow because each node is a new line. This is why C2's cost model was a model. constant time is not constant nanoseconds.

We will time two loops if we can do it honestly. We will not chase microbenchmark lies. CSAPP ch. 6 selected.
