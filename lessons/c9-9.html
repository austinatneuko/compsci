Objectives

  • Name undefined behavior as "the language does not promise a world."
  • List the UB we already hit: out-of-bounds, use-after-free, signed overflow, return-local.
  • Use sanitizers and warnings as the method.
  • Sit the C9 exit: draw stack/heap, find a memory bug with a method, write 100-line correct C.

Teaching

Undefined behavior is not "it crashed." It is "the standard allows the compiler to assume this never happens," so it may delete checks, format your disk in folklore, or appear to work until a demo. You will treat warnings and sanitizers as part of the compile. "It works on my machine" is the UB anthem.

Safety in C is discipline plus tools, not a type system like Rust, we are not switching languages. The exit is practical: draw, find a bug with a method, write correct C for a 100-line task. If a loop in hiring pokes OS/C, this is the course we schedule. we do not lower Gate A.
