Objectives

Teaching

React's model: you write a function of state and props that returns a description of the UI. React compares and updates the DOM. You do not surgically update a node unless you drop to an escape hatch. If you mutate a state object and wonder why nothing rendered, you did not change the state React knows about. State in, description out, React updates the tree. Mutating a state object in place is a non-update.

Official docs, selected. No tutorial-hell YouTube path. Hooks we need: useState, useEffect with a dependency array you can explain, later useMemo only if I say. You will not collect hooks like pins. useEffect needs a dependency array you can explain. We do not collect hooks.

Components are functions. Props are the arguments. Lifting state is the move when two children need the same fact. Prop-drilling through five layers is a smell we will name. A context API is a tool, not the first move.
