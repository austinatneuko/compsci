Hash tables

C2-lite Data Structures (pre-gate)

Locked. Because the prerequisite course is not mastered. You are on C0.1. You may read so the catalog is a real map. Do not start the exercises or the assigned reading until this lesson is current. Ratings do not move from a URL.

Objectives

  • Explain a hash table as array + hash function + collision plan.
  • Implement a chained hash map for a restricted key type.
  • State average vs worst-case lookup.
  • Know when a list beats a hash (and when it does not).

Teaching

A hash table gives you average constant-time lookup by turning a key into an index. The hash function is the turning. Collisions are the fact that two keys can land on the same index. Chaining (a list at each slot) is the plan we will implement first. Open addressing waits if we need it; I care that you have one complete, tested picture.

Average constant time is a sentence with assumptions: the hash is not terrible, the table is not absurdly full, the keys cooperate. Worst case is linear — everything in one bucket. You will say both sentences. “Hashmaps are O(1)” without the average is the kind of slogan that dies in a follow-up question.

Python’s dict is the professional tool. You still implement a small one so d[k] is not magic. Then you use dict and set like an adult. A list of pairs that you scan for every lookup is a hash table you refused to build; it is also sometimes the right thing when n is 4. C2.6 is about that judgment. This module is about the mechanism.

Resizing: when the load factor gets large, you allocate a bigger table and re-place the keys. You will implement a resize or explain exactly what breaks if you do not.

C2-lite is judgment plus implementation, not a museum of types. A structure is the operations you need and the bill they send when n grows. You already use lists and dicts; now you must be able to build the ones a junior actually needs and say when a list beats a hash. Heaps and graphs-as-ADTs wait until after the gate. That is not because they are optional forever. It is because the hiring bar uses lists, hashes, and trees, and we will not pretend you implemented a heap if we did not sit with one. Every module ends with costs you can say out loud.

A hash function is a promise about mixing, not a mystery. You will pick a simple one for integers or strings and watch collisions land in a chain. Resize is the other half of the promise: without it, chains become lists and the slogan dies. Average constant time is a sentence with assumptions. Say the assumptions. Then use dict like an adult.

Work

Exercises are listed so you can see the shape of the work. They are not assigned. Do not start them. No solutions on this site.

  1. Implement HashMap with get, set, delete, and a grow. Integer or string keys. Tests include collisions (force them if you must, with a tiny table).
  2. Closed-resource written: average vs worst-case; what load factor means.
  3. Compare dict vs scanning a list of pairs for n you choose. Numbers plus two sentences.
  4. No AI. Timed quiz.
