Objectives

  • Solve array and hash problems: frequency maps, two-sum shape, uniqueness.
  • State the memory trade: hash vs sort-first.
  • Handle duplicates on purpose.
  • Narrate before you type the second approach.

Teaching

A huge fraction of junior screens are: walk an array, remember what you have seen, answer a membership or count question. The hash table from C2 is the tool. The mistake is to sort when you needed membership, or to hash when you needed order. Membership and counts are hash problems. Order is not.

Two-sum shape: for each x, have I seen the complement. Anagrams: counts. Unique paths in a string: a set or a last-seen index. I will not enumerate every leetcode number. I will give you a small set we actually finish, with narration. A new two-sum shape should feel like a cousin, not a new language.

Duplicates and empty arrays are the tests. Interviewers watch the first edge, not your happy path. Write the edge in the first minute or say you are deferring it and then do not forget. Duplicates and empty are the first tests an interviewer watches.

Narrate the memory trade before you write the second approach. For each problem, one sentence: why hash, or why not. No solution blogs. No AI.

A set of problems I assign. Closed-resource first. Narrate in chat or live. Restate the problem. Give an example. Name the structure. Write. Walk an edge. If you skip the example you will mis-index.

C5-lite is interview-shaped algorithms you can narrate, not a second theory course. Asymptotics as sentences. Arrays and hashes. Two pointers and windows. Trees. BFS and DFS. One greedy and one DP you can tell as state, recurrence, base, order. NP and MST wait. Timed narration is the skill the gate coding exam will use. Silence plus a perfect function is still a fail in a loop. We grind a small set well enough to transfer. A fifty-problem streak you cannot explain is not this course.
