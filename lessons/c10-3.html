Files and I/O

C10 Operating Systems and Concurrency

Locked. Until Gate A. Systems depth and remaining CS wait until you can apply. You may read so the catalog is a real map. Do not start the exercises or the assigned reading until this lesson is current. Ratings do not move from a URL.

Objectives

  • Describe a file as bytes + metadata, and a descriptor as the process’s handle.
  • Explain buffering (user stdio vs kernel) as why “I wrote it” is not “it is on disk.”
  • Use this in a crash story: lost writes.
  • Keep sockets as “file descriptors that are not files” (C11).

Teaching

The kernel’s file API is the one your language wraps. Descriptors, offset, read/write/lseek. Directories are files of names (roughly). Permissions you already used in C0.2 are enforced here.

Buffering: libc’s fwrite may sit in user space until flush. The kernel may sit in page cache until a sync. A crash in the wrong window loses data. Databases care (C13). Your logger in C8 should have already met “line buffered or not.”

I/O homework from OSTEP or a small C program that copies a file with a buffer size you vary — I assign one.

OS and concurrency is processes, virtual memory, files, threads, locks, deadlock, a short scheduler, and one real artifact. OSTEP is the text. xv6 or a user-level thread package or a tiny filesystem — I designate one, not the whole MIT course. The exit is a concurrent bug you can fix with a named invariant, and a read you can explain. Just add a lock is a sentence we will kill with an example.

Descriptors, offsets, metadata. User buffers and kernel cache mean I wrote it is not it is on disk. A crash in the wrong window loses data. Databases care later. Your logger already met line buffering. Sockets are descriptors that are not files.

Concurrency bugs are not fixed by hoping. Name the invariant. Name the missing one. Change one thing. The artifact is there so you lived in the basement, not so you can sticker a portfolio. OSTEP homeworks are assigned chapters, not the whole book in a weekend. I designate the build so we finish.
