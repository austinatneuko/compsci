Teaching

Race: the user clicks item 1, then item 2. The response for 1 arrives last. If you do not ignore stale responses, you show the wrong item. We will write the bug, then the fix. This is a junior-level landmine and a gate-level debugging story. A stale response is a junior landmine: the user clicked twice and the first answer arrived last. Write the bug, then the fix.
