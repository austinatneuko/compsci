Sequences and dictionaries

C1 Programming Fundamentals in Python

Locked. Because C0 module 3, editor and terminal workflow, is not mastered yet. C1 can start in parallel only after that. You may read so the catalog is a real map. Do not start the exercises or the assigned reading until this lesson is current. Ratings do not move from a URL.

Objectives

  • Build, index, slice, and walk lists. Know that lists are mutable sequences.
  • Use dictionaries as maps from keys to values, not as lists with names.
  • Choose a list or a dict for a small job and say why.
  • Copy versus alias. b = a is not a second list.
  • Avoid the off-by-one errors you can catch with a trace.

Teaching

A list is an ordered, mutable sequence of objects. Those objects can have different types, but a list that means one thing should usually hold one kind of thing. You index from zero. You slice with a[i:j], which is a new list of the half-open interval. Include i, exclude j. That convention is not harassment. It makes a[:n] and a[n:] a clean split, and len(a[i:j]) equal j - i when the indexes are in range. Learn the half-open interval once. It comes back in every language you will use.

Mutation methods, append, extend, insert, pop, sort, change the list object. The functions sorted and slicing produce new lists. If you write xs = xs.append(3) you just bound xs to None, because append returns None. That bug will visit you. I am naming it now so you recognize the house.

A dictionary is a map. Keys must be hashable. Ints, strings, tuples of hashables. Not lists. Values can be anything. You look up by key, not by position. d[k] raises if k is missing. d.get(k) returns None or a default. Membership k in d is the normal check. Walking for k in d walks keys. Walk items with for k, v in d.items() when you need both. Using a dict as a clumsy list, keys 0, 1, 2, is a smell unless the keys are actually identities that happen to be numbers.

Alias versus copy is the C1.1 picture with teeth. b = a gives you two names for one list. b = a[:] or list(a) gives you a new list with the same items, shallow. Nested lists are a later knife. If you nest, say so and copy on purpose. I will put an alias bug on a quiz.

When do you pick which? Ordered collection you will walk in order, maybe duplicate, maybe sort, list. Lookup by an identity you already have, id, word, filename, dict. A set, unique membership, we will use when the job is have I seen this. Do not use a list and if x not in seen on large data as a lifestyle. For C1 sizes it runs, and I still want you to know it is the wrong structure later. C2 will make you implement these. Today you use them honestly.

Comprehensions are optional sugar this week. If you write one, you must be able to expand it to a loop. If you cannot, write the loop. Clever is not a grading category.

Strings are sequences too, but immutable. They wait in C1.5. Tuples are immutable sequences. Use them as records and as dict keys, not as lists I forgot to mutate.

Work

Exercises are listed so you can see the shape of the work. They are not assigned. Do not start them. No solutions on this site.

  1. Write mean(xs) that returns the arithmetic mean of a non-empty list of numbers. Raise a ValueError on empty. Return, do not print.
  2. Write a function that takes a list of words and returns a dict of word to count. Test it on a short list you can count by hand.
  3. On paper, a = [1, 2, 3], b = a, c = a[:], b.append(4). What are a, b, c? Then run.
  4. Given a dict of name to score, write a function that returns the name with the highest score. Define what you do on a tie and on empty, in the docstring.
  5. Closed-resource. No AI. Homework program 2 lives here.
