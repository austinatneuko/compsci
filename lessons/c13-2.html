C13 Databases as Systems

Locked. Until Gate A. Systems depth and remaining CS wait until you can apply. You may read so the catalog is a real map. Do not start the exercises or the assigned reading until this lesson is current. Ratings do not move from a URL.

Objectives

  • Treat an index as a B-tree, usually, or a hash, with a write cost.
  • Choose an index for a query and say what it cannot help.
  • Connect to C6.5 literacy; upgrade it.
  • Know covering / bitmap only if I assign a note.

Teaching

You implemented trees and hashes. An index is that, persisted, maintained on write. A second index is a second write. The primary key already has one. A composite index has a left-prefix story. EXPLAIN will show whether it was used.

Use The Index, Luke returns. I will give you a slow query and you will propose one index, not six.

C6 taught SQL as a user. This course treats Postgres as a program with a file and a planner. The planner is an optimizer with estimates that can be wrong. Your job is to read the plan and change the query, the index, or the schema, and say what happened.

Isolation is a story about two requests, not a level name you recited. Constraints remain the last line when the app is wrong. Document stores get an honest sentence, not a brand preference.
