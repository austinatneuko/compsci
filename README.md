# CompSci student site (v1.1)

Static HTML CSS and JS.
No package manager. No framework. No compile step to view.

Open locally: open index.html in a browser.
Or serve this folder with a local static file server on port 8080.

GitHub Pages: serve this folder as the repo root.
Relative links only. Do not use leading-slash domain paths.

Rebuild: python3 src/build.py

Ratings move only on demonstrated work, not by opening a page.

Layout: index, catalog, grades, about, courses/, lessons/, assets/

Example local server: python3 -m http.server 8080 then open 127.0.0.1:8080
